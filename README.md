## 👨‍💻 Sobre mí

Soy estudiante de **Ingeniería de Sistemas en la Universidad Nacional de Trujillo (X ciclo)**, enfocado en el **desarrollo web Full-Stack**. He desarrollado aplicaciones que conectan interfaces, APIs, bases de datos e inteligencia artificial, participando en distintas etapas del desarrollo, desde el diseño hasta el despliegue.

Me enfoco en construir soluciones funcionales y elegir tecnologías según las necesidades de cada proyecto. Actualmente busco **prácticas profesionales o posiciones junior** en desarrollo **Full-Stack, Frontend o Backend**.

**Plataforma web de bienestar emocional**

### 🩺 ObstetriCare
**Sistema de apoyo a la evaluación del riesgo de parto prematuro**

Aplicación que combina **Machine Learning y desarrollo Full-Stack** para estimar riesgos a partir de información clínica y apoyar la priorización de pacientes. Incluye gestión de pacientes y expedientes, **dashboards analíticos**, agenda médica y generación de reportes en PDF y Excel.

**Mi contribución:** frontend con React y TypeScript; backend con FastAPI y PostgreSQL; implementación de modelos **Random Forest, CatBoost y SVM** e integración de IA para recomendaciones.

**Tecnologías:** React · TypeScript · FastAPI · Python · PostgreSQL · Machine Learning
